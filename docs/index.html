About the edit

The Setup Edit is a small, independent guide to desks and home offices. Every pick is chosen for its design, its reviews and how well it fits the setup around it.

Picks come from research, not hands-on testing: I compare the options, read the specs and the reviews, and include the ones that suit each desk. Amazon links are affiliate links, which is how the site pays for itself.
